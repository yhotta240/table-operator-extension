## 設定方法

1. Chrome のツールバーから拡張機能アイコンをクリックしてポップアップを開きます．
2. `設定` タブで基本機能（列選択・並び替え・フィルター・エクスポート）のオン/オフを切り替えます．

## サイト別設定

1. `サイト別設定` の入力欄に対象の URL パターンを入力します．例:

   - `https://example.com` → example.com の全てのページに適用
   - `https://example.com/app` → そのパスにのみ適用
   - `https://*.example.com` → サブドメイン全てに適用

2. 入力ルール:

   - スペースは使用できません
   - `http://` または `https://` で始める必要があります
   - 同じパターンは重複登録できません

3. 追加するとリストに表示され，現在開いているタブにマッチするルールには「適用中」バッジが付きます．

## 表の操作

- 列ヘッダーをクリックしてソート（昇順/降順）できます．
- 列ヘッダーの入力でフィルターできます（部分一致）．
- 必要な列を選択してからエクスポートすると，選択列のみを CSV/TSV で保存できます．

## トラブルシューティング

- サイトルールが正しくマッチしない場合，URL パターンの形式を確認してください．
- エクスポートや保存が動作しない場合，ポップアップのログでエラーを確認してください．
