Web ページ上のテーブルを操作しやすくする Chrome 拡張機能です．列の選択，並び替え，フィルター，そして CSV/TSV 形式でのエクスポートを手軽に行えます．

## 主な特徴

- 列選択: 表の特定列を選択して強調表示できます．
- 並び替え: 列ごとに昇順／降順でソートできます．
- フィルター: 列ヘッダーから文字列で絞り込み可能です．
- エクスポート: 表の内容を CSV / TSV で保存できます．
- サイト別設定: サイト（URLパターン）ごとに各機能の有効/無効を設定できます．

## 注意点

- サイトルールは `http://` または `https://` を先頭に指定してください．ワイルドカード（`*`）を使ったマッチングに対応しています．
