Web ページ上の表を簡単に操作できるようにする Chrome 拡張機能です．列の選択，並び替え，フィルター，CSV/TSV エクスポートなどを手軽に行えます．

## 主な特徴

- 列選択: 表の特定列を選択して強調表示
- 並び替え: 列ごとに昇順／降順でソート
- フィルター: 列ヘッダーから文字列で絞り込み可能
- エクスポート: 表の内容を CSV / TSV で保存
- サイト別設定: サイト（URLパターン）ごとに各機能の有効/無効を設定

## 注意点

- 対象は標準の HTML の `table` 要素です（カスタム表や仮想化された表は非対応の場合があります）．
- エクスポートは「現在表示されているデータ」を出力します．機密データの取り扱いに注意してください．
